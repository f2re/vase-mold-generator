# Документация и релиз

Сначала читать AGENTS.md, PRODUCT.md и DESIGN.md.

Область записи: README.md, docs/, .github/workflows/, scripts/build-release.py.

Контракт: Сверить возможности с кодом. Приложить только реальные снимки, архивы, SHA256 и ограничения. Выпуск после зелёного CI; не включать пользовательские файлы или инструкции третьих сторон без лицензий.

Проверки: `Проверить состав ZIP, контрольные суммы и GitHub release/commit`.

Результат передачи: изменённые файлы, воспроизводимые команды, фактический вывод проверок и нерешённые ограничения. Не утверждать, что физическая печать выполнена.
