# Независимая проверка

Сначала читать AGENTS.md, PRODUCT.md и DESIGN.md.

Область записи: tests/, VALIDATION.md.

Контракт: Негативные файлы, размер, ориентация, попадание каналов, топология результата, отмена, гонки, Host/Origin/token, обратный импорт. Не менять критерии ради прохождения реализации.

Проверки: `npm test; python -m unittest discover -s tests -p test_*.py -v; браузерные сценарии`.

Результат передачи: изменённые файлы, воспроизводимые команды, фактический вывод проверок и нерешённые ограничения. Не утверждать, что физическая печать выполнена.
