Перед изменениями читать AGENTS.md, PRODUCT.md, DESIGN.md и docs/ENGINEERING.md.

Следовать последовательности Impeccable context/init + audit/critique → Taste только для выбора направления → нормализация по Impeccable → осмысленное движение по Emil → Impeccable audit/harden/optimize/polish. Закреплённые репозитории и пути находятся в skills.lock.json; локальные копии устанавливаются scripts/install-skills.py. Не считать этот краткий файл заменой upstream-инструкций.

Проверять работающее приложение и реальные STL. Разнесение, сечение и видимость не изменяют геометрию экспорта. Нельзя убрать широкую плашку или превратить полую втулку с глухим защёлкивающимся дном в сплошной сердечник. Не утверждать, что выполнялся CLI или физическая печать, без соответствующей проверки.
