## Детализация: что контролируется

Для окружности радиуса R и N сегментов максимальное радиальное отклонение хорды:
`e = R × (1 − cos(π/N))`. Округление N выполняется вверх. Профили новых дуг:
черновой 0,10 мм, обычный 0,03 мм, высокий 0,01 мм; своё значение 0,005–0,2 мм.
Для вазы допускается ручное количество сегментов; старые проекты с таким полем
сохраняют свой режим. Исходные грани загруженного STL не сглаживаются.

Для исходной вазы Ø150/Ø100 × 270 мм с принятыми в проекте зазорами:

|---|---:|---:|---:|---:|
| Черновой | 80 | 0,067845 | 9392 | 2228,6306 |
| Обычный | 128 | 0,026504 | 14960 | 2230,0277 |
| Высокий | 224 | 0,008655 | 26096 | 2230,6309 |

сеточный объём сходится к нему. При высоком профиле разница около **0,293 мл**.

## Многополигональность и дефекты

Треугольники в STL обязательны. Большое число граней не равно ошибке, а длинный
или узкий корректный треугольник не следует удалять ради визуально красивой сетки.
Рабочая деталь CSG должна иметь одну связанную оболочку, согласованные рёбра и
окружения вершин, не содержать дубликатов и нулевых граней. После CSG координаты
не округляются повторно для искусственного «лечения» щелей.

Проверка пересечений использует BVH, операции над треугольниками и двойную
точность Python. Допуск составляет `max(1e-8, размер × 2e-7)` мм, с учётом
float32-координат STL. Лимит по умолчанию — 500 000 пар и 10 секунд на сетку.
Проверка с достигнутым лимитом получает статус `incomplete`, не `clear`.
Рабочий CSG-результат при неполной проверке не выдаётся.

Это не библиотека точных геометрических предикатов. Предельные касания в одной
точке/по линии и особенности меньше допуска не исчерпываются данным тестом.
`geometryChecked` означает завершённую численную проверку в её пределах, а не
математическую гарантию. Самопересечения не исправляются скрыто. Для дефектного
мастера возможна только опалубка по контуру без вычитания контрольного силикона.

## Реальные ограничения

Опалубка остаётся выпуклым контуром в плане, не точным трёхмерным офсетом. Для
произвольного полого STL не создаётся автоматически тонкостенная внутренняя
вставка. Автоматический подбор разъёма/сердечников, уклоны, 3MF, раскладка по
столам и физическое моделирование течения отсутствуют.

Максимальное отклонение дуги не включает погрешность исходного STL, усадку,
ширину экструзии, точность принтера, деформации и свойства силикона. Печать,
герметичность, прочность и извлечение ещё не испытаны. Нельзя объявлять весь
комплект производственно проверенным только по зелёным тестам.
