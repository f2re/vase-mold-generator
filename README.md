# Vase Mold Generator · Опалубка

Локальный веб-конструктор печатной оснастки для цилиндрической вазы. **Размеры → интерактивная сборка → STL. Версия 0.2.1.**

Параметры, просмотр и экспорт используют одну геометрию. Здесь нет отдельной декоративной 3D-модели: каждая видимая деталь соответствует выгружаемой сетке. Приложение не отправляет модели на сервер.

## Запуск

Нужны Python 3.9+ и современный браузер. Node.js требуется только для тестов и командного экспорта. Нет npm-зависимостей, Docker, CDN и загрузки внешних шрифтов.

```bash
git clone https://github.com/f2re/vase-mold-generator.git
cd vase-mold-generator
python3 serve.py
```

Откроется `http://127.0.0.1:8765`. На macOS: `bash start.command`; на Windows: `start.bat` после установки Python. Другой порт: `python3 serve.py --port 8766`. Остановка: Ctrl+C. Сервер слушает только 127.0.0.1. Открытие через `file://` не поддерживается: модулям и Worker нужен HTTP.

## Что можно делать

| Управление | Результат |
|---|---|
| Сборка | Детали в исходных сборочных координатах |
| Разнесение и ползунок | Плашка, крышка, секции, втулка и дно раздвигаются для осмотра |
| Разрез и ползунок | Визуально отсекается часть сборки; STL не обрезается |
| Все детали | Отдельный обзор элементов; не раскладка по столам принтера |
| Список деталей / нажатие в 3D | Выделение, размеры, скрытие, изоляция, отдельный STL |
| Мастер-модель / Силикон | Контрольные тела отдельно от печатной оснастки |
| Открыть / Сохранить | Проект JSON с параметрами в миллиметрах |
| Скачать STL | ZIP комплекта с отдельными STL, параметрами и manifest.json |

Перетаскивание вращает, колесо масштабирует, Shift + перетаскивание или правая кнопка перемещает. Два пальца меняют масштаб. Стрелки вращают с клавиатуры, +/− меняют масштаб, F вписывает, Escape снимает выбор. Есть виды сверху/спереди, прозрачный кожух, снимок PNG и полноэкранный режим.

Изменение числа немедленно блокирует старый экспорт. Принимается только последний результат расчёта. Ошибка размеров не разрешает скачать устаревшую модель. Видимость и выделение сохраняются при пересчёте, если соответствующая деталь остаётся в комплекте.

## Исходная оснастка Ø150 / Ø100 × 270 мм

Принято: дно вазы 10 мм; силикон снаружи, внутри и под втулкой по 10 мм; перемычка над кромкой 5 мм. Толщина стенки вазы получается 25 мм.

В комплекте **10 рабочих деталей**: четыре секции наружного кожуха, основание, две секции полой втулки, её **глухое дно с четырьмя защёлками**, отдельная крышка полости и **широкая верхняя плашка с четырьмя окнами**. Пробная пара защёлки и три контрольные модели доступны отдельно.

Наружный Ø кожуха — 176 мм; Ø втулки — 80 мм. Для области 180 × 180 × 180 мм, боковых полей 2 мм и верхнего поля 10 мм рабочие детали помещаются. Целая контрольная ваза высотой 270 мм не помещается — это отдельно отмечено. Расход силикона: около **2,23 л без запаса**.

## Две заливки и границы применимости

Ваза стоит отверстием вверх. Первая заливка формирует наружный слой до её кромки. Вторая — внутреннее дно, стенки вокруг полой вставки и перемычку над кромкой. Для второй заливки предусмотрены предварительное заполнение внутреннего дна, медленное погружение глухой втулки и открытые окна плашки. Закрытая воздушная полость не исчезает от одной только дегазации смеси.

**Это опытная оснастка, без физической проверки печати и заливки.** Сначала печатать пробу защёлки. Вертикальные стыки, основание и плашка требуют внешней фиксации и герметизации. Время между слоями, сцепление, разделитель и подготовка гипса зависят от конкретного силикона. Программа не гарантирует отсутствие пузырей или лёгкое извлечение модели.

Подробный порядок, координаты и ограничения: [docs/ENGINEERING.md](docs/ENGINEERING.md).

Поддерживаются только параметрические цилиндрические вазы. Нет импорта произвольного STL, 3MF, расчёта поднутрений, слайсера или автоматической ориентации печати. Визуальные сечения не закрыты дополнительными торцами. WebGL имеет запасную отрисовку на CPU с буфером глубины; в локальных браузерных тестах этой поставки проверен CPU-режим, а не WebGL.

## Проверки и разработка

```bash
npm test
npm run example
python3 scripts/install-skills.py --check
# Только для разработчика:
python3 -m pip install playwright==1.57.0
python3 -m playwright install chromium
python3 tests/browser_test.py
# Проверка через запущенный локальный сервер:
VMG_TEST_URL=http://127.0.0.1:8765 python3 tests/browser_test.py
```

Локально прошли **25 тестов геометрии/экспорта и 25 браузерных проверок**. Все 15 исходных сеток замкнуты, имеют согласованную ориентацию и положительный объём. Это проверка сеток, не сертификат физической работоспособности. Условия запуска и непроверенные области — в [VALIDATION.md](VALIDATION.md).

`output/` содержит STL, комплект и пробную пару после `npm run example`. `artifacts/` — результаты браузерных тестов и снимки. Обе папки исключены из Git. GitHub Actions запускает проверки отдельно; статус CI не следует путать с локальным результатом.

## Правила для агентов и дизайн-скиллы

[AGENTS.md](AGENTS.md) задаёт порядок **Impeccable → Taste → Impeccable → Emil Kowalski → финальная проверка Impeccable**. Контекст — [PRODUCT.md](PRODUCT.md), закреплённый визуальный язык — [DESIGN.md](DESIGN.md), источники — [SOURCES.md](SOURCES.md).

```bash
python3 scripts/install-skills.py
```

Скрипт требует Git и сеть только при установке скиллов разработчика. Сохраняет три полных upstream-репозитория с лицензиями, проверяет SHA из `skills.lock.json` и создаёт локальные ссылки. Не запускает их CLI и хуки. На Windows ссылки могут потребовать дополнительных прав; прямые пути к инструкциям сохраняются. Обычному пользователю приложения этот шаг не нужен.
