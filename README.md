# Опалубка · Vase Mold Generator

**Из размеров или STL — в оснастку для 3D-печати.** Локальный конструктор с интерактивной сборкой, разрезом, разнесением деталей и экспортом STL.

## Три задачи, а не одна заготовка

| Режим | Исходные данные | Результат |
|---|---|---|
| **Ваза по размерам** | Наружный и внутренний диаметры, высота, дно | Разъёмный кожух, основание, полая втулка с защёлкивающимся дном, широкая верхняя плашка |
| **STL → опалубка** | Произвольный STL в пределах ограничений | Основание с наружным бортиком и две стенки вокруг выпуклого контура либо прямоугольника; деление стенок по высоте |
| **STL → жёсткий негатив** | Одна замкнутая ориентированная оболочка STL | Две половины с вычтенной полостью, четырьмя штифтами и гнёздами, литником и выбранными отдушинами |

**Опалубка и негатив — разные изделия.** Опалубка удерживает силикон вокруг мастер-модели. Негатив сам является жёсткой формой; для полостей, петель и выступов могут потребоваться другие разъёмы или съёмные сердечники. Генератор не заменяет проверку извлечения.

## Запуск

Нужен **Python 3.9+**. Для STL-расчёта дополнительно установите [OpenSCAD](https://openscad.org/downloads.html). Python-пакеты, Node.js, Docker, регистрация и облачный сервис для работы не нужны. Параметрическая ваза и просмотр своего STL работают без OpenSCAD.

```bash
git clone https://github.com/f2re/vase-mold-generator.git
cd vase-mold-generator
python3 serve.py
```

Браузер откроет `http://127.0.0.1:8765`. На Mac также доступен `bash start.command`, на Windows — `start.bat` при установленном Python. Другой порт: `python3 serve.py --port 8766`. Остановка — Ctrl+C.

OpenSCAD автоматически ищется в PATH, `/Applications/OpenSCAD.app` и стандартной папке Windows. Нестандартный путь:

```bash
VMG_OPENSCAD=/путь/к/openscad python3 serve.py
```

На Debian/Ubuntu: `sudo apt install openscad`. Инструкции для остальных систем — на странице производителя. В интерфейсе виден результат проверки CAD-ядра. Через `file://` приложение не запускается.

## От STL до комплекта

Откройте **«Загрузить STL»**, выберите файл или перетащите его в область загрузки. Примеры жетона, капсулы и кольца позволяют проверить процесс без собственной модели.

Проверьте **единицы, масштаб и ориентацию**: STL не хранит единицы. Предпросмотр сразу показывает реальные габариты. Выберите опалубку или негатив, задайте отступы и разъём. Для негатива можно назначить литник и добавить до восьми отдушин нажатием на поверхность в 3D. Каналы направлены вверх по Z; точка вне модели будет отклонена.

Нажмите **«Построить форму»**. Во время локального расчёта видны этапы; задание можно отменить. После изменения параметров прежний STL недоступен. Только результат актуального задания обновляет сцену и экспорт.

Проверьте сборку, разнесение и разрез, скройте мешающие детали или оставьте одну. Список справа показывает размеры и позволяет выгрузить отдельный STL. **«Скачать STL»** сохраняет ZIP рабочих деталей и сборочный манифест. **«Сохранить»** в STL-режиме создаёт JSON с исходным STL и параметрами — его можно открыть позже без повторного поиска модели.

![Жёсткий негатив: полость, установочные штифты и литник](https://github.com/f2re/vase-mold-generator/releases/download/v0.3.0/preview-stl-negative.png)

### Управление сценой

Перетаскивание вращает, колесо масштабирует, Shift + перетаскивание или правая кнопка перемещает. Стрелки вращают с клавиатуры, +/− меняют масштаб, F вписывает, Escape снимает выбор. Есть виды сверху/спереди, прозрачный кожух, снимок PNG и полный экран. Разнесение и разрез изменяют только просмотр, **не экспортируемую геометрию**. «Все детали» — обзор, не раскладка по столам принтера.

## Границы версии 0.3.0

| Проверяется | Не обещается |
|---|---|
| ASCII и binary STL, до 15 МиБ / 100 000 треугольников | Импорт OBJ, STEP, 3MF и неограниченно больших сеток |
| Конечные координаты, вырожденные/повторные грани, рёбра и ориентация | Полный ремонт самопересечений и повреждённых моделей |
| Замкнутость CSG-результата и реальные габариты каждой детали | Прочность, герметичность и успешная печать с любым профилем |
| Разъём X/Y/Z, штифты, реальные каналы в поверхности | Автоматический поиск оптимального разъёма и внутренних сердечников |
| Приближённая лучевая проверка поднутрений | Гарантия извлечения даже при нуле подозрительных лучей |
| Блокировка устаревшего или не помещающегося комплекта | Автоматическое разбиение больших оснований и половин негатива |

В режиме опалубки контур — **выпуклая проекция**, а не точный 3D-офсет каждой поверхности. Мастер касается основания; под его опорной поверхностью силикон не формируется. Наружные стяжки, герметизация и фиксация мастер-модели остаются частью процесса. Скругления и уклоны исходного STL не добавляются автоматически. Разрез в просмотре не закрывается дополнительными торцами.

**Физической печати и заливки этой оснастки ещё не было.** Сначала выполните пробу посадок и небольшой пробный отлив. Для жёсткого негатива интерфейс требует отдельно подтвердить необходимость проверки извлечения.

## Локальная архитектура

```text
Браузер                            Python на 127.0.0.1
├─ параметры вазы → Worker → STL   ├─ проверка запроса и STL
├─ STL: чтение и предпросмотр      ├─ очередь: один CAD-процесс
├─ масштаб, поворот, выбор каналов ├─ OpenSCAD: реальные CSG-операции
└─ сцена ← готовые сетки ←────────┴─ контроль результата
```

В обычном запуске нет внешних API, CDN или отправки моделей в интернет. Сервер принимает задания только с проверенным Host/Origin и токеном сессии, не исполняет пользовательский SCAD-код. Временные CAD-файлы удаляются, результаты хранятся ограниченно в памяти. Это **локальное приложение, не сервис для публикации в интернет**. Подробнее — [безопасность](SECURITY.md).

## Разработка и проверки

Node.js 18+ нужен только для тестов JavaScript и командного примера вазы. Playwright/Chromium — только для браузерных тестов.

```bash
python3 scripts/make-examples.py
npm test
python3 -m unittest discover -s tests -p 'test_*.py' -v
npm run example
python3 -m pip install playwright==1.57.0
python3 -m playwright install chromium
python3 serve.py --no-browser
# В другом терминале:
VMG_TEST_URL=http://127.0.0.1:8765 python3 tests/browser_test.py
VMG_TEST_URL=http://127.0.0.1:8765 python3 tests/browser_stl_test.py
```

Полный протокол и условия проверок — [VALIDATION.md](VALIDATION.md). CI повторяет проверки через HTTP и публикует релиз **только после успешного завершения тестов**. `scripts/build-release.py` собирает исходники, примеры оснастки и SHA256SUMS.

## Работа агентов

[AGENTS.md](AGENTS.md) закрепляет порядок **Impeccable → Taste по необходимости → Impeccable → Emil Kowalski → финальный аудит Impeccable**. Назначение продукта — [PRODUCT.md](PRODUCT.md), визуальная система — [DESIGN.md](DESIGN.md), закреплённые версии — `skills.lock.json`.

В [`.agents/roles/`](.agents/roles/) разделены задачи геометрии, интерфейса, проверки и релиза. Эти инструкции рассчитаны на подключённый оркестратор; наличие файлов не означает, что отдельные ИИ-агенты запускались. Установить upstream-инструкции: `python3 scripts/install-skills.py` — этот шаг нужен только разработчикам и требует сеть.
