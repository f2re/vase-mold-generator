# Проверки 0.3.0

## Локальные результаты

Проверены JavaScript (Node.js 22), Python 3.13, OpenSCAD 2021.01 и Chromium. Пользовательский запуск рассчитан на Python 3.9+; CI использует Python 3.12. Макет и механика не проверены реальной печатью.

| Набор | Результат | Область |
|---|---|---|
| `npm test` | 31 / 31 | Сохранённая геометрия вазы, STL/ZIP/JSON, ASCII/binary импорт, координаты, единицы, повороты |
| `python -m unittest discover -s tests -p test_*.py -v` | 32 / 32 | STL, рёбра, ориентация, CSG-опалубка, негатив по трём осям, штифты, каналы, отмена, таймаут, HTTP/CSRF/пути |
| `tests/browser_test.py` | 25 / 25 | Регрессия вазы: параметры, экспорт, 3D, разрез, видимость, клавиатура, JSON, мобильный экран |
| `tests/browser_stl_test.py` | 21 / 21 | Загрузка, настоящий CSG, повторная генерация, реальные каналы по клику, JSON со STL, отмена, ошибки и возврат к вазе |

Результаты относятся к выполненным командам; не заменяют статус удалённого CI. GitHub Actions повторяет сценарии через обычный HTTP перед публикацией релиза.

## Условия браузерного запуска

В локальной среде прямой переход Chromium к loopback запрещён политикой браузера. Поэтому регрессия вазы загружала действительные исходники через Blob-модули. STL-сценарий использовал те же исходники и ограниченный тестовый HTTP-мост к **реальному Python-серверу и OpenSCAD**: результаты CAD не подменялись. Это не проверка обычной браузерной доставки по HTTP в локальной среде; её выполняет GitHub CI.

Фактически использована отрисовка CPU / Canvas. Аппаратный WebGL, Safari/Firefox и реальные сенсорные устройства отдельно не испытывались. Десктоп и мобильный макет проверены на 1500 и 390 пикселях. Скриншоты получены из работающего интерфейса.

## Обнаруженное и исправленное

Повторное округление выходной сетки CSG удаляло тонкий допустимый треугольник у тестового кольца. Контроль рёбер не разрешал выдавать такой результат. Выход ядра теперь сохраняется без повторного грубого сшивания; входная сетка обрабатывается отдельно.

Исправлены неверная кратность шага поля масштаба, ошибочный вызов строкового поиска оси разъёма, видимость стадии CAD в основном окне и сброс подтверждения после изменения формы. Обычные технологические замечания перенесены под модель; критические предупреждения остаются заметными.

## Не подтверждено

Самопересечения общего вида, все варианты тонких деталей, крепёж и материал, герметичность, деформации, разборность, фактическое удаление воздуха, адгезия слоёв силикона и пригодность для пищевого/медицинского применения. Лучевой тест 11 × 11 не доказывает отсутствия поднутрений. Геометрически правильная форма может запирать отливку.

## Повторение

```bash
python3 scripts/make-examples.py
python3 scripts/check-all.py
python3 -m pip install playwright==1.57.0
python3 -m playwright install chromium
python3 serve.py --no-browser
# Другой терминал:
VMG_TEST_URL=http://127.0.0.1:8765 python3 tests/browser_test.py
VMG_TEST_URL=http://127.0.0.1:8765 python3 tests/browser_stl_test.py
```

`VMG_CHROMIUM` задаёт исполняемый браузер; `VMG_SCREENSHOT_DIR` — папку артефактов. Тестовый мост включается только явной переменной `VMG_TEST_BRIDGE=1`; в продукте его нет. Архивы и контрольные суммы собираются `scripts/build-release.py` после тестов.
