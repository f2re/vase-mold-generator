# Проверки версии 0.2.1

## Выполнено локально

- `npm test`: 25 из 25. Размеры, объёмы, две оболочки силикона, закрытое дно, проба защёлки, разбиение по высоте/диаметру, параметрические крайние случаи, корректность JSON, бинарные STL, ZIP и манифест, неизменность исходных сеток при экспорте.
- `npm run example`: все 15 исходных сеток замкнуты, ориентированы согласованно, имеют положительный объём. У каждого ребра две грани, вырожденные треугольники отсутствуют. Это не независимый анализ самопересечений произвольной сетки.
- `python3 tests/browser_test.py`: 25 из 25. Десктоп 1440 px и мобильный экран 390 px. Ввод и пересчёт, мгновенная блокировка старого STL, последний запрос, ошибки размеров, выделение/скрытие/изоляция, разрез, раскладка, клавиатура, скачивание STL/ZIP/JSON, обратная загрузка, этап второй заливки, отсутствие постоянной отрисовки и горизонтального переполнения, reduced motion.
- `python3 scripts/install-skills.py --check`: три записи lock-файла корректны. Установка с сетью в этой среде не выполнялась.

## Условия браузерного теста

В среде выполнения навигация браузера по HTTP заблокирована политикой среды. Использован `tests/browser_fixture.py`: реальные исходники и DOM загружаются через Blob-модули, меняются только пути импорта. Локальный Python HTTP-сервер проверяется отдельно. Этот тест не доказывает работу HTTP-загрузки в данном браузере; для неё предусмотрен `VMG_TEST_URL` и отдельный шаг GitHub Actions.

Фактически работал **CPU / Canvas**, включая программный буфер глубины. WebGL-код реализован, но аппаратный WebGL здесь не исполнялся. Safari, Firefox и реальные сенсорные устройства отдельно не проверялись. Снимки — результат работающего интерфейса, не генеративные иллюстрации.

## Не проверено физически

Не печатались защёлки и стыки, не измерялись посадки PETG, не испытывались герметичность, всплытие втулки, изгиб плашки, адгезия второго слоя, образование пузырей и извлечение готовой вазы. Нет расчёта прочности и течения. Габаритная проверка не подбирает поддержки и не гарантирует успешную печать.

## Как повторить

```bash
npm test
npm run example
python3 -m pip install playwright==1.57.0
python3 -m playwright install chromium
python3 serve.py --no-browser
# В другом терминале:
VMG_TEST_URL=http://127.0.0.1:8765 VMG_SCREENSHOT_DIR=artifacts python3 tests/browser_test.py
```

Исполняемый Chromium можно задать через `VMG_CHROMIUM`. Скрипт сохраняет browser-results.json, снимки, выгруженный ZIP и пробный STL. Состояние удалённого CI проверяется отдельно после публикации.
