# Изменения

## 0.3.0 — STL и две схемы оснастки

Добавлены ASCII/binary STL, единицы, масштаб, повороты и центрирование. Новый режим силиконовой опалубки строит основание и стенки по прямоугольнику или выпуклой проекции STL. Новый режим жёсткого негатива выполняет настоящее вычитание полости, разъём X/Y/Z, штифты, гнёзда, литник и до восьми отдушин.

Локальное CAD-ядро — установленный OpenSCAD, управление через Python без дополнительных библиотек. Есть очередь, отмена, таймаут, проверка запросов и сеток. Пользовательский SCAD не исполняется. В рабочий интерфейс добавлены выбор источника, загрузка перетаскиванием, примеры, выбор каналов по поверхности 3D, сохранение JSON со встроенным STL и блокировка старого экспорта.

Параметрическая ваза, втулка с глухим защёлкивающимся дном и широкая плашка сохранены. Обновлены правила агентной разработки, документация и публикация релиза через прошедший проверки CI. Геометрия не заменяет проверку физической печати, заливки, вентиляции и извлечения.

## 0.2.1

Полный локальный генератор параметрической вазы: общее ядро просмотра/STL, разнесение, разрез, список деталей, Worker, защёлка и плашка, русскоязычный интерфейс и тесты.
