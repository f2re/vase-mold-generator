# Безопасность локального запуска

Приложение предназначено для одного пользователя на 127.0.0.1. Не выставляйте его через nginx, туннель или публичный интерфейс без отдельной модели угроз и изоляции процессов.

STL не исполняется. Текст ASCII-STL разбирается строгим парсером и переписывается в двоичную сетку. Пользователь не может передать SCAD-код, команду, путь импорта или URL внешнего ресурса. В CAD входят только проверенные числа и фиксированное имя `model.stl`. OpenSCAD вызывается массивом аргументов без shell.

Сервер проверяет Host, Origin и токен сессии для изменяющих запросов и результатов CAD. CORS не разрешён. Доступ к .git, серверным исходникам, скриптам и выход за корневой каталог закрыт. HEAD использует ту же проверку путей. Проверки включают отрицательные HTTP-сценарии.

Ограничения: STL до 15 МиБ / 100 000 треугольников, JSON-запрос до 22 МиБ, не более двух активных/ожидающих заданий, один CAD-процесс, 120 секунд на расчёт. Результаты очищаются при последующих заданиях; старые завершённые задания удаляются по запросу после 30 минут. Это не жёсткая изоляция RAM/CPU процесса OpenSCAD и не песочница ОС.

Временные CAD-файлы находятся в системном временном каталоге и удаляются при завершении/отмене. При аварийном завершении всего Python-процесса обычная очистка ОС может потребоваться отдельно. В браузере автоматически сохраняются только числовые настройки параметрической вазы. Исходный STL попадает в JSON на диске только при явном сохранении проекта.

Сообщения об уязвимостях направляйте сопровождающему репозитория; не публикуйте чужие модели, токены сессии или приватные файлы в Issues.
